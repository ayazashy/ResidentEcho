# ResidentEcho 📊🏢
### Student Housing Community Feedback & Sentiment Dataset
### مستودع بيانات ملاحظات وشكاوى مجتمع السكن الطلابي

مستودع بيانات معالج ومنظم يضم أرشيف محادثات سكان المجمعات السكنية الطلابية عبر منصات التواصل (تليغرام وواتساب)، خاضع لعملية تعمية وتنقية شاملة للبيانات الشخصية وفق أعلى معايير حماية البيانات وسريتها.

## 🔒 معايير التعمية والخصوصية (Privacy & Anonymization)

تمت تعمية كافة البيانات الحساسة بحيث لا تحتوي الملفات المرفوعة على أي معلومات تعريف شخصية (PII):
1. **معرفات المستخدمين (`u`):** تم تحويل جميع أرقام الجوالات واليوزرات الحقيقية إلى معرفات رقمية اصطناعية مجهولة وثابتة لكل مستخدم:
   - مستخدمو التليغرام: تبدأ معرفاتهم من `1000000001`
   - مستخدمو الواتساب: تبدأ معرفاتهم من `2000000001`
2. **أرقام الجوالات:** تم استبدال كافة أرقام الهواتف وروابط التواصل بالرمز المعياري `[رقم_جوال]`.
3. **الأسماء والإشارات:** تم تحويل المنشنات والحسابات الشخصية والأسماء الصريحة إلى `@مستخدم` أو `[مستخدم]`.
4. **الملفات الأصلية:** تم عزل ملفات التصدير الخام (`*.txt` و `result.json`) وخزائن المطابقة بالكامل عبر `.gitignore`.

## 📋 بنية البيانات الموحدة (Schema Specification)

كلا المصدرين (تليغرام وواتساب) يتبعان نفس بنية الكائنات (JSON Schema) لتسهيل التحليل المباشر ونماذج الذكاء الاصطناعي:

```json
[
  {
    "i": 105,
    "d": "2025-09-15T14:30:00",
    "u": 1000000142,
    "t": "مكيفات مبنى 14 فيها مشكلة في التبريد",
    "r": 104
  }
]
```

### وصف الحقول:
- `i` *(int)*: الرقم التسلسلي / معرف الرسالة (Message ID).
- `d` *(string)*: تاريخ ووقت الرسالة بصيغة ISO-8601 المعيارية (`YYYY-MM-DDTHH:MM:SS`).
- `u` *(int)*: المعرف الرقمي المجهول للمرسل (Anonymized User ID).
- `t` *(string)*: نص الرسالة بعد التعمية والتنظيف.
- `r` *(int, اختياري)*: معرف الرسالة المردود عليها (Reply To Message ID) في حال وجود رد.

## 🚀 طريقة قراءة البيانات في بايثون (Quickstart)

```python
import json
import gzip

# قراءة بيانات التليغرام المضغوطة مباشرة
with gzip.open("ChatExport_2026-10-13/compressed.json.gz", "rt", encoding="utf-8") as f:
    telegram_messages = json.load(f)

# قراءة بيانات الواتساب المضغوطة مباشرة
with gzip.open("ChatExport2_2026-10-13/compressed.json.gz", "rt", encoding="utf-8") as f:
    whatsapp_messages = json.load(f)

print(f"Telegram Messages: {len(telegram_messages):,}")
print(f"WhatsApp Messages: {len(whatsapp_messages):,}")
```
