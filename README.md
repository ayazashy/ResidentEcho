# ResidentEcho 📊🏢
### Student Housing Community Feedback & Sentiment Dataset
### مستودع بيانات وتحليل ملاحظات وشكاوى مجتمع السكن الطلابي — جامعة الملك سعود

مستودع بيانات ومنصة تحليلية متكاملة تضم أرشيف محادثات سكان المجمعات السكنية الطلابية عبر منصات التواصل (تليغرام وواتساب)، خاضعة لعملية تعمية وتنقية شاملة للبيانات الشخصية وفق أعلى معايير الخصوصية، مع خط أنابيب ذكي للتحليل اليومي، والتجميع العنقودي الشهري للمشكلات (Issue Clustering)، ولوحة تحكم تفاعلية ثابتة تدعم النشر المباشر عبر GitHub Pages.

---

## 🌐 لوحة التحكم التفاعلية (Live Web Dashboard)

يتضمن المستودع لوحة تحكم تفاعلية خفيفة وثابتة بالكامل (**Static Web Application**) مبنية باستخدام Vanilla HTML5/CSS3/JavaScript دون الحاجة لأي خادم خلفي أو بيئة تشغيل معقدة، وهي جاهزة تماماً للنشر عبر **GitHub Pages**.

### 🌟 مميزات لوحة التحكم:
- **تصميم خفيف وأنيق (Light & Minimalist):** خط Cairo العربي، تخطيط RTL أصيل، تجربة مستخدم سريعة وخالية من التعقيد.
- **استعراض عناقيد المشكلات (Issue Clusters):** عرض المشكلات المحورية المصنفة مع مؤشرات الحدة (حرج، مرتفع، متوسط)، عدد الرسائل، ونسبة المستخدمين المتأثرين.
- **معاينة الرسائل الحقيقية (Real Message Previews):** استعراض الرسائل الفعلية للطلاب التابعة لكل مشكلة مع تفاصيل المنصة (تليغرام / واتساب)، الطابع الزمني، ومعرف المستخدم المشفر.
- **البحث الفوري بمعرف الرسالة (Message ID Lookup):** إمكانية البحث المباشر برقم أي رسالة في ثوانٍ عبر فهرس المعرفات المدمج (`id_index.json`).
- **أدوات الفرز والتصفية:** تصفية بحسب المنصة، الحدة، الكلمات المفتاحية، والترتيب الزمني.

### 💻 التشغيل المحلي السريع (Local Run):
```bash
# تشغيل خادم محلي ثابت في ثوانٍ
python3 -m http.server 8000
# ثم افتح المتصفح على: http://localhost:8000
```

## 🔒 معايير التعمية وحماية الخصوصية (Privacy & Anonymization)

تمت تعمية كافة البيانات الحساسة بحيث لا تحتوي الملفات المرفوعة على أي معلومات تعريف شخصية (PII):
1. **معرفات المستخدمين (`u`):** تم تحويل جميع أرقام الجوالات واليوزرات الحقيقية إلى معرفات رقمية اصطناعية مجهولة وثابتة:
   - مستخدمو التليغرام: تبدأ معرفاتهم من `1000000001`
   - مستخدمو الواتساب: تبدأ معرفاتهم من `2000000001`
2. **أرقام الجوالات:** تم استبدال كافة أرقام الهواتف وروابط التواصل بالرمز المعياري `[رقم_جوال]`.
3. **الأسماء والإشارات:** تم تحويل المنشنات والحسابات الشخصية والأسماء الصريحة إلى `@مستخدم` أو `[مستخدم]`.
4. **الملفات الأصلية:** تم عزل ملفات التصدير الخام (`*.txt` و `result.json`) وخزائن المطابقة بالكامل عبر `.gitignore`.

## 📋 بنية البيانات الموحدة (Schema Specification)

```json
[
  {
    "s": "tg",
    "i": 105,
    "d": "2026-09-15T14:30:00",
    "u": 1000000142,
    "t": "مكيفات مبنى 16 فيها مشكلة في التبريد ويطلع منها غبار",
    "r": 104
  }
]
```

### وصف الحقول:
- `s` *(string, اختياري)*: المنصة المصدر (`tg` للتليغرام، `wa` للواتساب).
- `i` *(int)*: الرقم التسلسلي / معرف الرسالة الفريد (Message ID).
- `d` *(string)*: تاريخ ووقت الرسالة بصيغة ISO-8601 القياسية (`YYYY-MM-DDTHH:MM:SS`).
- `u` *(int)*: المعرف الرقمي المجهول للمرسل (Anonymized User ID).
- `t` *(string)*: نص الرسالة بعد التعمية والتنظيف.
- `r` *(int, اختياري)*: معرف الرسالة المردود عليها (Reply To Message ID).

## 🚀 طريقة قراءة واستخدام البيانات (Quickstart)

### 1. عبر بايثون:
```python
import json
import gzip

# قراءة مخرجات العناقيد لشهر سبتمبر 2026
with open("monthly_analysis/2026-09_analysis.json", "r", encoding="utf-8") as f:
    clusters_data = json.load(f)

print(f"Clusters: {clusters_data['clusters_count']}")
for c in clusters_data['clusters']:
    print(f"- {c['title_ar']}: {c['total_messages_count']} msgs")
```

### 2. استعراض لوحة التحكم على GitHub Pages:
يمكن تفعيل GitHub Pages مباشرة باختيار فرع `main` والمجلد الرئيسي `/ (root)` من إعدادات المستودع (Settings -> Pages)، لتعمل لوحة التحكم فوراً دون أي إعداد إضافي.
